# Data Analysis & Visualization Project

## Overview

This project demonstrates the process of collecting, cleaning, exploring, analyzing, and visualizing data using Python.

The project is organized into several stages to document the data analysis workflow from data collection through final visualization and presentation.

## Project Structure

### `data_collection`
Contains the files and code used to collect and prepare the initial data.

### `data_wrangling`
Contains the work used to clean, transform, and prepare the data for analysis.

### `exploratory_data_analysis`
Contains the analysis performed to explore the data, identify patterns, and generate insights.

### `data_visualization`
Contains the Python code and visualizations created to communicate the findings.
